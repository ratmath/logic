@ratmath/logic

Logic where every verdict comes with its evidence

Formal logic you can compute with. A formula is valid with a proof, invalid with a countermodel, or reported as unresolved; proofs written by hand are checked line by line, with hints when a step is missing.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • Propositional formulas: truth tables, normal forms, satisfiability, simplification.
  • Proof checkers for the common rule sets (natural deduction, sequents, axioms), with proof search and hints.
  • Predicate logic: syntax, finite models, search for countermodels, the quantifier rules.
  • Circuits, Karnaugh maps and syllogisms.
  • Modal logic with Kripke models.
  • Ordinals, cardinals, Peano arithmetic and Gödel numbering.
  • Automata, grammars and Turing machines.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
