Reference

Every export, grouped by subject. Wherever a formula is expected, text such as "p -> q" is accepted; wherever several are, an array or text with commas.

Answers

Functions that decide something return an object with a status and the evidence for it:

StatusEvidence
"satisfiable", "invalid", "different"model or countermodel: a valuation, checked by evaluating the formulas.
"unsatisfiable", "valid", "equivalent"refutation: a resolution proof, checked step by step.
"proved"proof or derivation, checked by the proof checker for that system.
"unprovable"kripke: a Kripke model in which the formula fails. Intuitionistic logic only.
"unresolved"reason and the budget that ran out. Pass a larger budget to go further.

Arguments the library cannot work with are refused with a LogicError carrying a code: syntax, bad-argument, too-large or bad-proof.
