Resolution

Resolution is a proof system with a single rule, working on clauses. It is the form in which the solver hands over its evidence: when it says a formula is valid, it gives a resolution refutation that a few lines of code can check.

The rule

A clause is a disjunction of literals. If one clause contains xxx and another contains ¬x\lnot x¬x, then whichever way xxx goes, one of the remaining parts must be true:

C∨xD∨¬xC∨D \frac{C \lor x \qquad D \lor \lnot x}{C \lor D} C∨DC∨xD∨¬x​

The clause below the line is the resolvent on xxx. Resolving xxx against ¬x\lnot x¬x leaves the empty clause □\square□, which nothing satisfies. A list of clauses is unsatisfiable exactly when □\square□ can be reached from it by resolution: such a derivation is a refutation.

import { clause, resolve, showClause } from "@ratmath/logic";

showClause(resolve(clause("p, q"), clause("~p, r"), "p"));   // "q ∨ r"

Proofs from the solver

To show that premises entail a conclusion, refute the premises together with the negated conclusion. entails and valid do this and return the refutation.

import { entails } from "@ratmath/logic";

const result = entails("p -> q, q -> r", "p -> r");
result.status;                 // "valid"
String(result.refutation);
// 1. p        premise
// 2. ¬p ∨ q   premise
// 3. ¬q ∨ r   premise
// 4. ¬r       premise
// 5. ¬q       resolve 4, 3 on r
// 6. ¬p       resolve 5, 2 on q
// 7. □        resolve 6, 1 on p
result.refutation.check();     // { ok: true, refutation: true, errors: [] }

The premises of the refutation are the clauses of (p→q)∧(q→r)∧¬(p→r)(p \to q) \land (q \to r) \land \lnot(p \to r)(p→q)∧(q→r)∧¬(p→r). For a large formula the clauses come from the Tseitin form, and the refutation records the definitions it used in definitions.

The solver is a DPLL search: it sets a variable, simplifies, and backs out when a clause becomes false. Each time it backs out it has, in effect, resolved two clauses, and the refutation is the record of those steps. The search is the complicated part and the check is the simple part, so a mistake in the search cannot produce a wrong "valid".

Checking a refutation written by hand

import { checkResolution } from "@ratmath/logic";

const text = `
1. {p, q}     premise
2. {~p, q}    premise
3. {~q}       premise
4. {q}        resolve 1, 2 on p
5. {}         resolve 4, 3 on q`;
checkResolution(text);          // { ok: true, refutation: true, errors: [] }

checkResolution(text.replace("on p", "on q")).errors[0].message;
// "line 4: lines 1 and 2 do not clash on q: one must contain q and the other ¬q"

Clauses may be written with braces and commas or as disjunctions. Pass { premises } to require that every premise line is one of the clauses you were given. refutation is true when the proof is correct and reaches the empty clause.
